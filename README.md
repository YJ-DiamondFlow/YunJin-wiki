# YunJin-wiki

云锦巡梦音游战队官方 Wiki —— 前后端分离版本。

> 逻辑与 `YJ-wiki`（静态站点）保持一致，但在其基础上做了 UI 美化、亮/暗双主题、
> 登录注册、页面在线编辑以及后台管理功能。

---

## 技术架构

| 层 | 技术 | 说明 |
| --- | --- | --- |
| 前端 | **Vue 3 + Vite**（Node.js 生态） | 单页应用，客户端路由，含亮/暗主题切换 |
| 后端 | **纯 Python（仅标准库）** | `http.server` + `sqlite3` + `hashlib`，零第三方依赖 |
| 存储 | SQLite | 用户、会话、页面内容及编辑历史 |

- 后端**不依赖任何第三方 Python 包**，直接运行即可，无需 `pip install`。
- 前端依赖 `vue`、`vue-router`、`marked`、`dompurify`，由 `npm` 安装。

```
YunJin-wiki/
├── backend/                 # 纯 Python 后端
│   ├── server.py            #   HTTP 服务入口（API + 静态托管）
│   ├── api.py               #   接口路由
│   ├── auth.py              #   密码哈希 / 会话
│   ├── db.py                #   SQLite 数据层
│   ├── config.py            #   配置（端口 / 管理员账号 / 角色）
│   └── content_seed.py      #   初始页面内容
├── frontend/                # Vue3 + Vite 前端
│   ├── src/
│   │   ├── views/           #   页面（首页/成员/关于/考核规则/…/登录/注册/编辑/后台）
│   │   ├── components/      #   侧边栏、顶栏、图标
│   │   ├── store.js         #   登录态 + 主题
│   │   └── style.css        #   亮/暗主题变量与全部样式
│   └── vite.config.js
├── data/wiki.db             # 首次启动自动生成的数据库
└── README.md
```

## 快速开始

### 1. 构建前端（首次或前端改动后执行）

```bash
cd frontend
npm install
npm run build          # 产物输出到 frontend/dist
```

### 2. 启动后端（会同时托管前端）

```bash
python backend/server.py
```

打开浏览器访问 <http://127.0.0.1:8000> 即可。

> 也可直接双击根目录的 `start.bat`（Windows）一键构建并启动。

### 开发模式（可选）

前后端分离热更新：

```bash
# 终端 1：后端
python backend/server.py

# 终端 2：前端（Vite 已配置 /api 代理到 127.0.0.1:8000）
cd frontend && npm run dev   # 访问 http://localhost:5173
```

## 角色与权限

| 角色 | 说明 | 编辑页面 | 访问 `/admin` | 管理用户 | 审核 |
| --- | :---: | :---: | :---: | :---: | :---: |
| `admin`（超级管理员） | 内置账号 | ✅ 立即生效 | ✅ | ✅（含授予子管理员） | ✅ |
| `sub_admin`（子管理员 / 普通 admin） | 由超管授予 | ⏳ 提交后需超管审核 | ✅ | 仅查看 | ❌ |

- 未登录用户访问编辑入口会先跳转登录页。

## 添加 / 删除页面 & 页面审核流程

### 添加新页面
- 在 `/admin` →「页面管理」标签页右上角的「**添加新页面**」按钮进入创建页（`/new-page`）。
- 需填写：页面标识（slug，决定访问地址 `/wiki/xxx`）、标题、正文（Markdown，右侧实时预览）。
- 新建的页面会自动出现在左侧导航的「其他」分组中。

### 删除页面
- 在「页面管理」列表每行的「**删除**」按钮可删除页面（有二次确认）。
- **首页（`index`）为站点入口，受保护不可删除**，其余页面均可删除。

### 审核流程
- **超级管理员**（`DiamondFlow`）的新建 / 修改 / 删除：**立即生效**。
- **子管理员**（普通 admin）的新建 / 修改 / 删除：**不会直接生效**，而是生成一条「待审核」申请，并给超级管理员发送站内消息。
- 超级管理员在 `/admin` →「待审核」标签页可查看申请内容（新增/修改支持预览），选择 **通过并生效** 或 **驳回**（可填写驳回理由）。
- 审核结果会以站内消息形式通知提交人；子管理员可在「我的提交」标签页查看自己所有申请的审核状态。

### 站内消息
- 顶栏 🔔 图标显示未读消息数；点击可查看消息列表、逐条已读或「全部已读」。
- 触发时机：子管理员提交申请 → 通知超级管理员；审核通过 / 驳回 → 通知提交人。

## 注册登录说明

- 仅需 **用户名 + 密码**，**不需要手机号，也不需要邮箱验证**。
- **用户名不可重复**（后端唯一约束 + 友好提示）。
- **不接入任何第三方账号平台**。
- 密码使用 `PBKDF2-HMAC-SHA256`（12 万次迭代 + 随机盐）加盐哈希后存储，明文不落库。
- 登录后签发随机会话 Token（有效期 7 天），前端存于 `localStorage`。

## 主题与视觉风格

- **亮色主题**：以**白色为主、黑色为辅**。主按钮使用反色墨块（黑底白字）。
- **暗色主题**：以**黑色为主、白色为辅**。主按钮自动反转为白底黑字。
- 右上角 ☀️/🌙 按钮可随时切换，选择会记忆在浏览器中（`localStorage`）。

视觉语言为 **Concept / Editorial-Tech** 风格，刻意保持克制与"高级感"：

- 以 **1px 细边框 + 发丝分割线**构建层级，几乎不使用投影（取代圆润卡通感）。
- 全局统一 **小圆角**（2 / 4 / 6 / 10px），不使用胶囊形大圆角。
- **黑白为主、单一强调色**：强调色只出现在细线、指示条、链接与图标上。
- 背景叠加极低对比的 **72px 网格**，营造工程制图般的氛围。
- 标签 / 徽章 / 状态胶囊采用「轻底色 + 同色细边框」，而非实心色块。
- 数字统一使用 **等宽数字（tabular-nums）**，元信息（slug、时间、标签）使用等宽字体。
- 登录 / 注册页为 **左右分栏**：左侧墨块（亮色下为黑、暗色下为白）承载品牌，右侧为表单。

所有颜色、圆角、字号均集中定义在 `src/style.css` 顶部的 CSS 变量中，改一处即可全站生效。

## 静态资源与缓存策略

前端每次构建都会生成**带内容哈希的新文件名**。为了避免浏览器仍引用已被删除的旧文件
（典型症状：登录 / 注册 / 后台页点不动、输入框打不了字、页面加载不出来），后端做了如下处理：

| 请求 | 行为 |
| --- | --- |
| `/assets/*`（带扩展名的资源）存在 | `200`，`Cache-Control: public, max-age=31536000, immutable` |
| `/assets/*` 不存在 | **`404`**（而不是回退成 index.html） |
| `/login`、`/wiki/xxx` 等无扩展名路由 | `200` 回退到 `index.html`（SPA 前端路由） |
| `index.html` | `Cache-Control: no-cache, no-store, must-revalidate` |

前端还有两层自愈保护：

1. **路由懒加载失败自动恢复**：检测到「分片已不存在」时，自动整页跳转到你本来想去的地址，拿到最新版本（10 秒内只触发一次，避免死循环）。
2. **启动兜底提示**：若 6 秒内应用仍未挂载完成，页面会显示「页面加载失败 / 点此刷新」而不是卡在空白假死状态。

> 如果你手动改过前端并重新 `npm run build`，**正在浏览的旧页面需要刷新一次**（`Ctrl + Shift + R`）才会加载新版本。
